# Especificações Oficiais

As SPECs desta pasta são documentos oficiais subordinados aos CANONs.

Hierarquia:

```text
CANON-00
↓
CANON especializado
↓
SPEC aplicável
↓
ADR / operação / implementação
```

| Código | Versão | Status | Proprietário de domínio |
|---|---:|---|---|
| `SPEC-PORTFOLIO-00` | `1.0.0` | APROVADO | portfólio / esteira / arquitetura comercial |
| `SPEC-MEU-CAMINHO-001` | `2.0.0` | APROVADO | Meu Caminho / continuidade / arquitetura funcional do sistema |
| `SPEC-STACK-00` | `1.1.0` | APROVADO | arquitetura técnica / stack / infraestrutura |
| `SPEC-MELHORIAS-SEO-001` | `1.0.0` | APROVADA PARA BACKLOG | SEO institucional, SEO local e rastreamento |

Regras:

- SPEC não altera CANON;
- documento mais especializado governa detalhes se não contrariar fonte superior;
- hipóteses dentro de uma SPEC continuam hipóteses;
- decisões abertas continuam abertas;
- implementação histórica não prevalece sobre SPEC aprovada;
- mudanças estruturais exigem aprovação conforme governança.
